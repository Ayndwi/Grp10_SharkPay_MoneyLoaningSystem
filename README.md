# Money Loaning System

## Project Overview

The Money Loaning System is a Java-based application designed to manage
customers, loan applications, repayments, and credit history.

The system provides separate functions for customers and administrators.

## Features

### Customer
- Register an account
- Log in
- Apply for a loan
- View loan information
- Repay loans
- View loan history
- Log out

### Administrator
- Manage clients
- View loan applications
- View credit history
- Add credit liens for overdue accounts
- Log out
